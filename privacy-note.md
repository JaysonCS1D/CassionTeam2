# Privacy Note

## Project: Python Task Manager App

---

## What Data We Collect

The Task Manager App collects only the following data provided directly by the user:

| Data Field   | Purpose                                        |
|--------------|------------------------------------------------|
| Task title   | Identify the task                              |
| Description  | Provide task details                           |
| Due date     | Track deadlines                                |
| Status       | Track completion (pending or completed)        |
| Timestamps   | Record when tasks were created and completed   |

---

## What We Do NOT Collect

- No names, emails, or personal identity information (current version)
- No location data
- No device or browser information
- No usage analytics or tracking data
- No cookies

---

## Data Storage

- Currently stored in memory only — data is not saved between sessions
- Future versions will use a local SQLite database on the user's machine
- No data is sent to any third parties

---

## User Rights

- Users can view all their stored tasks at any time
- Users can delete any task at any time
- No data is shared, sold, or used for advertising

---

## Changes to This Policy

If this privacy note is updated, the team will notify users through the project's
GitHub repository. The date of the last update will be noted at the top of this file.
